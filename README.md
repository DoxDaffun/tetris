# Unit Optimizer / ユニット最適化

ブラウザで `index.html` を開いてください。スマホでも利用できます。

## 盤の種類

| 盤 | サイズ | テーマカラー |
|----|--------|------------|
| セグウェイ | 8×7 = 56マス | 青 |
| スケボー   | 8×9 = 72マス | 紫 |
| 馬         | 8×12 = 96マス | 赤 |

「使用」チェックで盤を有効化し、「メイン」ラジオでどれをメインにするか選択。  
最適化時はメイン盤を優先して埋め、残りのユニットを他の盤に配置します。

## 品質（グレード）

低 → 高の順:

| 品質 | 呼称 | 色 |
|------|------|----|
| 1 | 緑 (good) | 黄緑 |
| 2 | 青 (better) | 青 |
| 3 | 紫 (excellent) | 紫 |
| 4 | 紫+1 (excellent+1) | 紫（スパークル） |
| 5 | 金 (epic) | 金/オレンジ |
| 6 | 金+1 (epic+1) | 金（スパークル） |
| 7 | 赤 (legend) | 赤 |

## 使い方

1. **盤の選択** — 使用する盤を選び、メインを指定
2. **所持ユニット** — 品質7×形状5=35項目に各所持数を入力
3. **最適化** — 「最適化」ボタンでツールが自動で回転・配置を最適化
4. **未使用ユニット** — 配置できなかったユニットが下部に表示
5. **手動配置** — 「手動配置」ボタンで形状・品質を選んで盤面をクリック
6. **塗る / 消す** — 盤面を直接クリックして品質セルを手書き
7. **盤面リセット** — 全盤をリセット（所持ユニット設定は維持）

## 形状

- **O**: 2×2正方形
- **I**: 1×4直線
- **T**: T字
- **L**: L字
- **J**: J字（逆L）

回転は最適化時に自動で全方向を考慮します。
