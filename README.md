# Line Optimizer / ライン最適化

ブラウザで `index.html` を開くと、8x6 盤面に対して以下を実行できます。

- A: 自動ソルバー（最適配置）
- B: 手動配置 + ヒント

## ルール実装

- 形状: O, I, T, L, J（S/Z なし）
- 各ピースは 4 マス
- 重力なし・空中配置可
- 回転可能。向きは入力で選択（O=1, I=2, T/L/J=4）
- 目的関数:
  1. 完成水平ライン数の最大化
  2. 同数なら、完成ライン上の色優先スコア最大化

色優先度: 黄緑 < 青 < 紫 < キラ紫 < オレンジ < キラ橙 < 赤

## 使い方

1. `Pieces / 手持ち` でピースごとに shape / orientation / color を設定
2. 盤面クリックでプリセット配置（Paint/Erase）
3. 自動なら `Solve`、手動ならドラッグまたはピース選択→盤面クリックで配置（⟳ボタン / Rキーで回転）
4. `Hint` で候補表示、`Apply Hint` で反映
5. `Reset Board` と `Reset All` で初期化
